# R10-O2 — `residual_flexibility` for a truncated modal FRF

## What landed

`femtools.dynamics.residuals.residual_flexibility` — a public **function** returning the
static (MacNeal / Ewins upper) residual flexibility block, shaped `(n_out, n_in)` and
ready to hand to `modal_frf(..., upper_residual=...)`.

```python
from femtools.dynamics.residuals import residual_flexibility

UR = residual_flexibility(K, M, truncated, inputs=[drive], outputs=[tip, mid])
H = modal_frf(truncated, [drive], [tip, mid], f, damping, upper_residual=UR)
```

`UR = K^-1 F - sum_retained phi_r phi_r^T F / w_r^2` (Ewins, *Modal Testing*, §4.2;
Craig & Kurdila, *Fundamentals of Structural Dynamics*, ch. 21; MacNeal residual
flexibility). No proprietary sources.

Signature:

```python
residual_flexibility(K, M=None, modal=None, force_dofs=None, *,
                     forces=None, outputs=None, inputs=None,
                     tol=1e-10, rigid_tol_hz=1e-4) -> np.ndarray
```

* The numbers come straight from `residual_vectors`, i.e. from
  `ResidualVectorResult.residual_flexibility` selected through
  `ResidualVectorResult.upper_residual`. **The attribute was not renamed** and the method
  was not touched — the function is a thin, frozen entry point onto them, so the free-free
  inertia relief and the rigid-body-pinning static solve behave identically.
* When neither `force_dofs` nor `forces` is given, `inputs` doubles as the set of unit
  load directions, so the call mirrors `modal_frf`'s own `inputs`/`outputs` and the
  returned block is already the right shape.
* Passing an already-solved `ResidualVectorResult` as the only positional argument
  re-slices it without a second static solve; combining it with `M`/`modal`/loads raises
  `TypeError`.

## Gate — measured relative L2 against `direct_frf`

`err = ||H_modal - H_direct||_F / ||H_direct||_F` over 300 lines of
`retained_band_lines(kept, 300)` (the 0.2–0.8 retained-fmax band), Rayleigh damping
tuned to ζ = 2 % at the first and last retained mode so both sides carry the same
physical `C` and differ by modal truncation alone.

| case | band (Hz) | no residual | with `residual_flexibility` | ratio |
| --- | --- | --- | --- | --- |
| 16-element BEAM2 cantilever, 4 modes, drive at tip `uz`, sense tip + mid | 7.73–30.93 | **1.9023 %** | **0.1314 %** | 0.069 (14.5× better) |
| grounded 24-mass spring chain, 4 modes, drive at mass 24, sense 24 + 12 | 2.25–9.01 | **4.8020 %** | **0.6988 %** | 0.146 (6.9× better) |

Both assertions in the gate are `err_corrected < err_plain` and
`err_corrected < 0.25 * err_plain`; the measured ratios above leave a wide margin.

Same cantilever, other truncations (not asserted, for context): 3 modes
1.2380 % → 0.0459 %; 6 modes 0.8859 % → 0.1296 %; 8 modes 2.9077 % → 0.5419 %.

## Other tests in `tests/test_round10_o2.py`

* the block equals `inv(K)[sense, drive]` minus the retained modal sum, term by term
  (`rel=1e-12`), and a drive-point residual is positive;
* a **complete** basis leaves a residual at round-off (`< 1e-12` of `max|K^-1|`);
* the block is exactly `ResidualVectorResult.residual_flexibility` sliced (bit-identical,
  `atol=0`), and the `ResidualVectorResult` passthrough equals `upper_residual`;
* `(n_out, n_in)` shape follows the `outputs`/`inputs`/`force_dofs` selection;
* free-free chain: `phi_rb^T M UR` is below `1e-9` of `max|UR|` — inertia relief leaves no
  rigid-body drift in the residual;
* `TypeError` on `residual_flexibility(K, M)` and on mixing a result with `M`/`modal`;
* the name is in `residuals.__all__` and importable from `femtools.dynamics`.
