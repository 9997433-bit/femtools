## 4. Algorithm notes added (public literature, matching existing style)

- `docs/algorithms/fea.md` **§10** stress/strain recovery — differentiate-then-constitute
  at the element centroid sharing the element's B/D code paths; per-type recovery points
  (CST/TET4 exact constant strain, QUAD4 centroid as the Barlow superconvergent point,
  BEAM2 Hermite curvature resultants at ξ=1/2, HEX8 centroid where the incompatible-mode
  strain vanishes identically so no re-solve of the condensed α is needed); frames,
  von Mises, and the 1e-12 constant-strain patch gate. Refs: Cook et al. 4th ed.;
  Barlow IJNME 10 (1976); Bathe §4.3.6.
- `docs/algorithms/fea.md` **§11** RBE2 condensation — small-rotation rigid kinematics
  u_d = u_i + θ×r as the [[I, −S(r)],[0, I]] block, null-space transform u = Tq with
  K̂ = TᵀKT / M̂ = TᵀMT / f̂ = Tᵀf, exact RBM preservation (the 6-RBM welded-pair gate)
  and the moment-carrying offset via S(r)ᵀ in Tᵀf; MPC-before-SPC ordering, raise on
  SPC'd dependents / double-dependents / chains; conditioning note (lever arms, no
  penalty ratio). Refs: Cook et al. ch. 13; Craig & Kurdila §14.
