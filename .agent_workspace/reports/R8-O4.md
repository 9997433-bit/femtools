Branch `cursor/r8-o4-static-update-d551`, based on `origin/cursor/femtools-cycle-c-d551`.

## What landed

### 1. `update_from_static` (frozen API) — `src/femtools/updating/updater.py`

```python
from femtools.updating.updater import update_from_static   # frozen spelling
from femtools.updating import update_from_static           # also exported
```

```python
update_from_static(model, measured, parameters=None, dofs=None, *,
                   loads=None, solver=None, solver_kwargs=None, scale=None,
                   response=None, **update_model_kwargs) -> UpdateResult
```

It is a wrapper, not a new estimator: it builds the response with the Round-7
`static_displacement_response` and runs the existing damped Gauss–Newton loop of
`update_model` (Friswell & Mottershead, *Finite Element Model Updating in
Structural Dynamics*, ch. 3). No numerics were added or changed.

What the wrapper actually contributes:

* **`measured` in test-data spellings.** `{(node, "uz"): value}`,
  `{node: {"uz": value}}`, `{"u": [...], "dofs": [...]}`, or a plain vector plus
  `dofs=`. The DOF spellings are whatever `static_displacement_response` already
  accepts (`"uz"` / `2` / `{node: "xyz"}` / `DOFSet` / global equation numbers).
  `dofs=None` measures at the loaded DOFs, i.e. the drive points of the test.
* **A default parameter.** `parameters=None` updates one relative Young's-modulus
  multiplier over every material, starting at 1.0 inside `(0.1, 10)` — the
  one-line call the brief asked for.
* **Round-off convergence defaults.** A static residual is smooth and cheap, so
  the loop runs with `tol=1e-14`, `residual_tol=0`, `max_iter=60` instead of the
  modal-flavoured `1e-6`/`1e-12`/`30`. Any `UpdateOptions` field passed as a
  keyword overrides these; everything else (`weights`, `bounds`, `p0`, `prior`,
  `callback`, …) is forwarded to `update_model` untouched.
* **`UpdateResult.model` is populated.** `update_model` only writes the model
  back when it drives the FEA itself; with a `response=` callback it returns
  `model=None`, so the wrapper applies the converged parameters to a fresh deep
  copy. The input model is never mutated.
* **A DOF/target count check** before the first solve, so 3 gauges against 2
  numbers is an error rather than a silent truncation.
* `response=` accepts any callable, which is how the stress residual below is
  driven through the same entry point.

### 2. `static_stress_response` (optional item) — `src/femtools/updating/responses.py`

```python
static_stress_response(model, parameters, elements=None, *,
                       component="von_mises", quantity="stress",
                       frame="element", layer="mid", loads=None,
                       solver=None, solver_kwargs=None, scale=None)
```

The stress counterpart of `static_displacement_response`: it solves the linear
static problem and pushes the result through `femtools.fea.recover.recover_stress`,
returning one number per requested element. `component` is `"von_mises"` or a
Voigt component; `quantity="strain"` reports what a gauge rosette actually reads;
`frame="basic"` rotates out of the element frame first; `elements=[...]` selects
and orders the rows (row indices are resolved once and cached).

This was cheap exactly as the brief hoped: `recover_stress` is consumed as a
library call, so **no file under `fea/**` or `io/**` was touched.**

## Measured results (all from `tests/test_round8_o4.py`)

Every case uses the classic 10 % modulus error, so the multiplier being chased is
`1/1.1`; "error" below is `|p·1.1 − 1|`, the relative parameter error.

| Case | Residual | Parameter error | Iterations |
|---|---|---|---|
| BAR2 axial bar, 1 tip extension | static displacement | **4.44e-16** | 6 (19 solves) |
| BAR2 axial bar, 3 frequencies | modal (reference path) | 1.80e-10 | 3 |
| BEAM2 cantilever, 3 deflections | static displacement | **2.65e-13** | 6 |
| BAR2 chain, 2 materials, 4 stations | static displacement | < 1e-9 both | — |
| HEX8 constant-stress patch, 8 von Mises | stress | **0.0** (exact) | 5 |
| BAR2 chain stretched, 4 σxx | stress | **1.11e-16** | 4 |

So the static path does not merely reach "the same order as the modal path" — on
the clean axial bar it is about six decades tighter, because `u = FL/(AE)` is
exactly inversely proportional to the modulus multiplier while the modal residual
carries an eigensolve tolerance. The requirement was ~1e-9; the test asserts
1e-11 on the bar and 1e-9 on the cantilever, with headroom.

Recovered modulus on the bar: 209 999 999 999.9999 Pa against a truth of 2.1e11 Pa
(4.36e-16 relative).

### The constant-stress patch

`hex_patch()` in the test file is the classical constant-strain patch test: a
3×3×3 grid of unequal stations (8 HEX8 bricks) with the 26 outer nodes driven by
the exact linear field `u = G·x` and the enclosed node displaced 0.09/−0.07/0.08
off centre and left free.

* the free node lands on the linear field to 2.7e-20 (absolute);
* every element reports the same stress: von Mises spread across the 8 elements
  is **3.56e-16** relative;
* that stress matches `D(E)·ε` to 4.7e-16 relative;
* since `solid_D` is exactly linear in `E`, updating against those 8 measured von
  Mises values recovers the multiplier **exactly** (error 0.0, 5 iterations).

The 1-D analogue is the rod chain stretched by a prescribed end displacement: the
axial force is constant through the chain, so σ is constant (spread 3.99e-16)
and equals `E·δ/L` to 1e-12.

## Notes for the parent

* `static_stress_response` is **not** in the Round-8 frozen list, so
  `docs/PRODUCT_MAP.md` / `femtools/__init__.py` need not carry it; it is a
  documented member of `femtools.updating.__all__` and nothing more.
* Driving a stress residual needs a load case in which stress depends on the
  parameter. Under dead force loading a statically determinate structure has
  σ = F/A regardless of E, so the patches above are driven by **prescribed
  displacement** (`solver_kwargs={"enforced": ...}` reaches `solve_static`).
  That is worth a line in the algorithm notes if R8-F3 documents this.
