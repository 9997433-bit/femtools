# R2-O1 — HEX8 抗剪切闭锁

**Branch:** `cursor/r2-o1-hex8-incompatible-modes-9f14` (base `cursor/femtools-sota-d551`, 无 PR)
**Scope:** `src/femtools/fea/**`
**Test baseline:** `pytest -q` → 17 passed / 3 skipped，`FEMTOOLS_PERF=1 pytest tests/perf` → 3 passed，`ruff check src/femtools/fea` 干净。

## 1. 做了什么

### 1.1 HEX8 非协调模式（Wilson/Taylor）成为默认

`hex8` 现在在 24 个位移自由度之外增加 9 个内部自由度，携带三个二次泡函数
`1-ξ²`、`1-η²`、`1-ζ²`（每个泡函数带 3 个位移分量），再做静力凝聚：

```
K = Kuu − Kua Kaa⁻¹ Kauᵀ
```

内部模式的梯度按 Taylor–Beresford–Wilson 修正映射：用**单元中心**的 Jacobian
`J0`，再乘 `det J0 / det J`。这保证 `∫ B_enh dV = 0`，即畸变网格上仍然精确通过常应力
patch test（实测 6e-16，见 §2.3）。

凝聚矩阵是一个半正定矩阵的 Schur 补，其零空间就是原矩阵零空间在位移分块上的投影；
泡函数一定产生非零应变，所以零空间恰好是 6 个刚体模态——不会引入沙漏机构（§2.4、§2.5 实测）。

### 1.2 三种可选积分方案

`HEX8_FORMULATIONS = ("incompatible", "bbar", "full")`，从 `femtools.fea` 导出，
连同归一化函数 `hex8_formulation()`（接受 `IM`/`Wilson`/`Q6`/`b-bar`/`SRI`/
`selective reduced`/`2x2x2` 等别名，非法值抛 `ValueError`）。

| 名称 | 含义 |
|------|------|
| `incompatible`（默认） | 上述非协调模式 |
| `bbar` | 平均膨胀 / 选择性缩减积分（体积项取中心点，偏量项 2×2×2）。**与 SRI 逐位等价**：矩形单元上两种实现的 `‖K_SRI − K_bbar‖∞ / ‖K‖∞ = 2.2e-16` |
| `full` | 原 2×2×2 三线性单元，保留作参考与 patch test 基准 |

选择顺序：单元记录 → 属性记录 → `assemble_km(options={"hex8": ...})` → 默认。
键名 `hex8` / `hex8_formulation` / `solid_formulation` / `formulation` 均可
（刻意不认 `integration`：未来 `PSOLID` 读入器很可能拿这个名字表示别的东西）。
实测属性级覆盖优先于装配级（`max|ΔK| = 0`）。

**故意不提供 `incompatible + bbar` 组合**：两种拼法都不可用，实测结果记录在 §3。

### 1.3 顺带修掉的 `solve_modes` 缺陷（同属 `fea/`）

`_rayleigh_ritz_refine` 每一轮都用移位反迭代的**像**替换基底。移位
`σ = −1e-9 · max(K_ii/M_ii)` 把刚体模态映射到弹性谱之上九个数量级，于是：

- **自由-自由模型**：三轮之后每一列都收敛到刚体子空间，`_m_orthonormalize`
  的 1e-12 秩截断把弹性列全部丢掉——`solve_modes(n_modes=10)` 对自由-自由
  HEX8 块**只返回 6 个模态**，而且没有任何告警。
- **约束模型**：基底丢失 M-正交性，Ritz 投影 `eigh(ZᵀKZ)`（假定 `ZᵀMZ = I`）
  失效，凭空造出谱外的零 Ritz 值——10 单元悬臂 HEX8 梁返回
  `[0, 0, 0, 6.328]`，正确答案是 `[6.328, 6.328, 38.38, 38.38]`。

修法：每轮只把反迭代像中**新增的**方向并入基底（两遍 Gram–Schmidt，按
"投影前后 M-范数之比 > 1e-8" 筛掉纯舍入噪声），Ritz 投影前重新 M-正交归一化，
并给子空间加上列数预算。修后 12 组约束/自由算例对稠密 `scipy.linalg.eigh`
参考解的最大相对误差 ≤ 2.3e-11（见 §2.6）。

### 1.4 新增 `femtools.fea.verification`

把文档与测试引用的验收算例集中到一处（纯 dict 模型，不 import `core.model`，
保持内核解耦）：`hex_cantilever`、`timoshenko_tip_deflection`、
`hex8_bending_ratio`、`hex8_patch_test_error`、`hex8_rigid_body_frequencies`。
测试属主（R2-G*）可以直接调用，不必重写建模代码。

## 2. 数值结果

参考解为 Timoshenko 端部挠度 `PL³/(3EI) + PL/(κGA)`，`κ = 5/6`，
`L=10, b=h=1, E=1e7, ν=0.3, P=1` → `4.0312e-4`。

| 网格 | `full` | `bbar` | `incompatible` |
|------|-------:|-------:|---------------:|
| 1×1×1 | 0.0252 | 0.0256 | **0.7261** |
| 2×1×1 | 0.0922 | 0.0987 | **0.8965** |
| 4×1×1 | 0.2780 | 0.3481 | **0.9601** |
| 10×1×1 | 0.6428 | 1.1972 | **0.9855** |
| 20×1×1 | 0.7931 | 1.8410 | **0.9913** |
| 40×1×1 | 0.8429 | 2.1278 | **0.9932** |

**验收目标（>~90%）在 10×1×1 上达成 98.55%**，4 单元即已达 96.0%。

### 2.2 泊松比扫描（10×1×1）

| ν | `full` | `bbar` | `incompatible` |
|---|-------:|-------:|---------------:|
| 0.0 | 0.6660 | 0.9225 | **0.9965** |

Taylor 修正生效，非协调模式在畸变网格上仍精确。

## 3. 已知局限（如实记录）

1. **`bbar` 在薄弯曲件上过软**。厚度方向 1 个单元时挠度比随网格加密发散
   （10×1×1 = 1.20，40×1×1 = 2.13）。这是平均膨胀单元的固有性质：它松弛的是
   真实存在的体积应变梯度能量。`bbar` 只应用于厚实的近不可压缩件（8×4×4 及以上
   实测 0.89–0.96）。docstring 已明确写出这条警告。
2. **不提供 `incompatible + bbar`**。两种拼法都实测失败：
   - 对泡函数也做平均膨胀投影 → 规则单元刚度阵出现 **9 个零特征值**（6 刚体 + 3 伪机构），
     10×1×1 悬臂挠度比 141.9；
   - 只对协调部分做投影 → 秩正确（6），但 λ₇ 从 1.23e6 掉到 1.95e5，
     悬臂挠度比 3.48。
     稳定的组合需要 Simo–Rifai EAS 的另一组增强应变基，属于 R3 议题。
3. **非协调模式对单元畸变敏感**（已知性质）。平行四边形畸变的 6 单元悬臂：
   skew=0 → 0.9754，skew=0.2 → 0.6403，skew=0.4 → 0.3646。
   仍在每个畸变水平上优于 `full`（0.4446 / 0.3551 / 0.2358）和 `bbar`
   （0.6553 / 0.4922 / 0.3077），但畸变网格不能指望 90% 精度。
4. **内部自由度不参与质量矩阵**（业界通行做法），一致质量阵与 `full` 完全相同。
5. **应力恢复未实现**，所以内部幅值 α 在凝聚后被丢弃。将来若加 HEX8 应力输出，
   需要重新恢复 α = −Kaa⁻¹ Kauᵀ u，届时要把 `Kaa⁻¹Kauᵀ` 缓存下来。
