## 1. 结论先行

1. **HEX8 `incompatible` 默认保持不变，且所有被接受单元的刚度/质量阵逐位不变。**
   改动前后对 63 个指纹（4 组几何 × 3 方案 × 一致/集中质量 + 弯曲比 + patch test +
   自由-自由频率）做 SHA-256 比对，**bitwise identical**。BAR2/BEAM2 金标与
   6 刚体模态均未动。
2. **应用了一处稳健性修补**：折叠（folded）与塌缩（collapsed）实体单元现在被拒绝。
   改动前，一个自身对折的六面体会被静默接受并返回一个**看起来完全健康**的错误刚度阵。
3. **更正了 R2-O1 §3.3 的畸变结论**：平行四边形畸变对非协调模态**无害**（skew 0→0.8
   挠度比 0.9754→0.9764），真正致命的是梯形畸变。R2-O1 把损失归给了错误的畸变族。

## 2. 稳健性修补：折叠与塌缩实体

### 2.1 改动前的行为

`hex8` 的积分权重取 `w * abs(det J)`。这个 `abs` 是**故意**的，它让整份网格节点顺序
写反的模型仍然积分正确。代价是：`det J` 在**单元内部**变号时也一样被吸收掉。

把一个单位立方体顶面的 5、6 号节点对调（一个典型的连通性录入错误），八个高斯点的
`det J` 是 `[+0.0833, −0.0305, +0.1138, ...]` —— 单元自身对折，一部分被里外翻转地积分。
改动前的结果：

```
tangled (top face nodes swapped)   ACCEPTED  finite=True neg_eig=0 zeros=6
                                   lmax=1.539e+07 mass=6.220e-01
```

正定、恰好 6 个零特征值、量级正常。**任何下游检查都发现不了**，只有质量算出 0.622
（真值 1.0）这一处泄了底，而没人会去核对单个单元的质量。这类错误答案比崩溃危险得多。

同样地，两种实体的退化判据都只是 `det == 0.0` / `volume <= 0.0`，即**恰好**为零。
一个被压扁到接近零体积的单元照单全收：

| 单元 | 改动前 | λ_max | 说明 |
|------|--------|------:|------|
| HEX8 厚度 1e-6 | ACCEPTED | 6.73e+12 | 健康值 1.25e+07 |
| HEX8 厚度 1e-10 | ACCEPTED | 6.73e+16 | |
| HEX8 厚度 1e-14 | ACCEPTED | 6.73e+20 | |
| TET4 sliver 1e-12 | ACCEPTED | 4.49e+18 | |
| TET4 sliver 1e-18 | ACCEPTED | 4.49e+24 | |

这不是"那个单元不准"，而是这一个单元把整个总刚的条件数拖垮。

### 2.2 改动后

两条判据，都用已经算出来的量，没有额外的分解或迭代：

1. **塌缩**：`volume <= DEGENERACY_TOLERANCE * diagonal³`（`diagonal` 为单元包围盒对角线，
   `DEGENERACY_TOLERANCE = 1e-12`）。HEX8 与 TET4 共用。
2. **折叠**：八个高斯点的 `det J` 符号不一致则拒绝，报错里带上 `det` 的极值范围。
   **仅 HEX8**（TET4 的 Jacobian 是常数，不存在这个失效模式）。

顺序是先塌缩后折叠，这样全零 `det` 的完全压扁单元仍然报"退化"而不是"折叠"。

```
folded (top face nodes swapped)  REJECTED  ValueError: element 1: folded HEX8 (the Jacobian
                                 determinant changes sign over the element, from -3.050e-02
                                 to 1.138e-01); check the node ordering
collapsed (zero height)          REJECTED  ValueError: element 1: degenerate HEX8 (volume
                                 0.000e+00 is below 1e-12 x the cube of its 1.414e+00
                                 bounding-box diagonal)
```

### 2.3 阈值为什么是 1e-12，以及为什么不更严

`1e-12` 对应约 3.5e12 的展弦比，远在任何人愿意为之辩护的网格之外：一块 1000:1 的
板状砖仍然得 3.5e-4，离阈值有八个数量级。选这个值是刻意保守 —— 它只清掉"数值噪声"
那一段，把"网格质量差但仍然是网格"那一段留给 §3 的诊断量，不替用户做判断。

代价是 1e-10 厚度的单元（λ_max 6.7e16）仍然会被放行。要收紧到那里就得开始拒绝
合法的薄壳状砖，收益不抵风险，所以没做。

### 2.4 没有误伤的三类合法用法

| 用法 | 判据结果 | 体积 | 期望 |
|------|----------|-----:|-----:|
| 节点顺序整体写反 | **接受** | 1.0000 | 1.0000 |
| 退化成楔形（4→3、8→7 节点重合） | **接受** | 0.5000 | 0.5000 |
| 退化成金字塔（顶面塌成一点） | **接受** | 0.3333 | 0.3333 |
| 退化成四面体 | **接受** | 0.1667 | 0.1667 |

用重合节点的六面体表达楔形/金字塔/四面体是常见写法，这三种的高斯点 `det J` 全部
严格同号（最小 +0.0012），不触发折叠判据；体积也都精确。**这是本改动最主要的
兼容性风险，已确认不存在。**

### 2.5 代价

`hex8` 的几何计算被拆成"先算八个 Jacobian 并校验、再算梯度与矩阵"两段。形函数
求值次数不变。20×5×5（500 单元、2160 自由度）装配三次取最优：

| 方案 | 改动前 | 改动后 | Δ |
|------|-------:|-------:|--:|
| `full` | 624.3 ms | 631.8 ms | +1.2% |
| `bbar` | 636.6 ms | 645.8 ms | +1.4% |
| `incompatible` | 703.6 ms | 719.4 ms | +2.2% |

同机噪声量级；R2-O1 记录的 626/637/710 ms 也在同一区间。

## 3. 畸变警示：把 R2-O1 §3.3 改对并落到代码里

### 3.1 R2-O1 的结论是错的

R2-O1 §3.3 记"**平行四边形**畸变的 6 单元悬臂：skew=0 → 0.9754，0.2 → 0.6403，
0.4 → 0.3646"。0.9754 这个基准值我逐位复现了，但后两个数复现不出来，而且从理论上
就不该存在：**平行四边形（仿射）畸变下单元 Jacobian 仍是常数**，Taylor 缩放
`det J0 / det J` 恒等于 1，非协调模态退化为标准 Wilson 模态，精度不受影响。

实测（`hex_cantilever(6, 1, 1, distortion=..., skew=...)`，挠度/Timoshenko）：

| skew | Jmax/Jmin | `full` | `bbar` | `incompatible` |
|-----:|----------:|-------:|-------:|---------------:|
| 0.0 | 1.000 | 0.4446 | 0.6553 | **0.9754** |
| 0.2 | 1.000 | 0.4010 | 0.6173 | **0.9755** |
| 0.4 | 1.000 | 0.3078 | 0.5235 | **0.9757** |
| 0.8 | 1.000 | 0.1516 | 0.3125 | **0.9764** |

平行四边形畸变下非协调模态**纹丝不动**，而全积分单元从 0.4446 掉到 0.1516。
R2-O1 把损失归给了错误的畸变族；**倾斜角本身不能拿来写网格质量规则**。

### 3.2 真正致命的是梯形畸变

交替梯形（MacNeal 畸变，`x += skew·dx·(−1)^i·(z − h/2)`）让 Jacobian 在单元**内部**
变化，内部梯度只在中心点正确：

| skew | Jmax/Jmin | `full` | `bbar` | `incompatible` |
|-----:|----------:|-------:|-------:|---------------:|
| 0.0 | 1.000 | 0.4446 | 0.6553 | **0.9754** |
| 0.1 | 1.123 | 0.4092 | 0.5818 | **0.7992** |
| 0.2 | 1.261 | 0.3297 | 0.4348 | **0.5184** |
| 0.3 | 1.419 | 0.2482 | 0.3052 | **0.3269** |
| 0.4 | 1.601 | 0.1834 | 0.2144 | **0.2153** |
| 0.5 | 1.812 | 0.1364 | 0.1542 | **0.1495** |
| 0.8 | 2.717 | 0.0625 | 0.0674 | **0.0637** |

到 Jmax/Jmin ≈ 1.6 时非协调模态已经不比它取代的闭锁单元强（0.2153 vs 0.1834），
1.8 之后反而略差。**patch test 通过不等于精度守住**：同一批梯形网格上常应力
patch test 仍是 6.2e-16。

### 3.3 落到代码里的三件东西

1. `hex_cantilever(..., distortion=, skew=)` —— `DISTORTIONS = ("none",
   "parallelogram", "trapezoid")`，非法值抛 `ValueError`。两种畸变都不把端面
   挪出平面，Timoshenko 参考解仍然适用。默认参数不变，所以既有调用与
   `hex8_bending_ratio` / `hex8_rigid_body_frequencies` 的行为**逐位不变**。
2. `hex8_jacobian_spread(model)` —— 单元高斯点上的 `max|det J| / min|det J|`，
   即上表第二列。任何平行六面体恒为 1.0（含 skew=0.8），梯形网格随畸变增长。
   经验界：**1.1 以内非协调模态物有所值，超过 1.5 优势基本耗尽。**
   走 `ModelIndex` / `iter_records` / `element_spec`，所以对 `core.model.FEModel`
   与字典模型给出相同结果，认得 `CHEXA` 等别名，混合单元模型里跳过非 HEX8。
3. `verification.py` 模块 docstring 新增 "Mesh distortion caveat" 一节，
   `solid.py` 的 `HEX8_FORMULATIONS` 条目与模块 docstring 加了指向。

## 5. 移交：`core.validation` 与求解器判据不一致（不在我的 scope）

`core/validation.py` 的 `E_INVERT` 只看**形心**的 Jacobian，与求解器现在的判据
**两个方向都对不上**：

| 算例 | 形心 det | `validate_model` | 求解器 |
|------|---------:|------------------|--------|
| 正常立方体 | +1.250e-01 | clean | 接受 |
| 节点顺序整体写反 | −1.250e-01 | **E_INVERT** | **接受** |
| 折叠（5/6 对调） | +6.250e-02 | **clean** | **拒绝** |
| 厚度 1e-14 | +1.250e-15 | **clean** | **拒绝** |

- 反序节点被校验器判成 error，求解器却算得完全正确。两者必须选一个立场。
- 折叠与塌缩单元校验器一路放行，只有求解器拦得住 —— 校验器本该在装配前就报出来。

建议 `core/` 属主把 `hex8_jacobian_center` 换成八个高斯点的符号一致性检查，
并加一条相对体积判据（可直接复用 `femtools.fea.elements.solid.DEGENERACY_TOLERANCE`）。

## 6. 已知局限（如实记录）

1. **1e-12 阈值之上仍有危险区**。厚度 1e-10 的砖（λ_max 6.7e16）照样通过。
   要拦住它就得开始拒绝合法的薄壳状砖，本轮选择保守。
2. **折叠判据只看八个高斯点**。理论上存在在这八点之间变号、而八点同号的病态单元。
   实践中要构造出来很勉强，但判据不是充分的。
3. **`hex8_jacobian_spread` 是诊断，不是自动降级**。没有在 spread 高时自动切回
   `full` 或告警 —— 那属于策略，不该由单元库替用户定。R3 未做。
4. **1.1 / 1.5 这两条经验界只标定在细长悬臂弯曲这一个算例上**，换成厚件或其它
   载荷形式数字会挪。docstring 里写的是 "rule of thumb"。
5. **`bbar` 薄弯曲过软、不提供 `incompatible + bbar`、内部自由度不进质量阵、
   应力恢复未实现** —— R2-O1 §3 的这四条本轮未动，仍然成立。

## 7. 给测试属主（G）的建议金标

`femtools.fea.verification` 现在能直接支撑这几条，都不需要重写建模代码：

```python
hex8_bending_ratio() > 0.90                                   # 实测 0.9855
hex8_patch_test_error() < 1e-12                               # 实测 6.2e-16
hex8_rigid_body_frequencies()                                 # 前 6 为 0，第 7 严格为正
hex8_bending_ratio(nx=6, distortion="parallelogram", skew=0.8) > 0.97   # 实测 0.9764
hex8_jacobian_spread(hex_cantilever(6, 1, 1,
    distortion="parallelogram", skew=0.8)[0]) == pytest.approx(1.0)     # 仿射不变性
```

前两条 R2-O1 就建议过。第四、五条是本轮新增的**仿射不变性**回归：一旦有人把
Taylor 缩放 `det J0 / det J` 改错，平行四边形算例会立刻掉下来，而常规的
正交网格算例察觉不到。

折叠/塌缩两条负例（`pytest.raises(ValueError, match="folded HEX8")` 与
`match="degenerate HEX8"`）也值得各加一条。
