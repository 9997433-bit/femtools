## Changes made (examples adapted to the real merged APIs, per brief item 5)

- **`mac_demo.py`** — `pair_modes` merged signature is
  `pair_modes(phi_a, phi_b, freq_a, freq_b, *, mac_threshold=...)` returning a
  `PairingResult` of `ModePair(index_a, index_b, mac, ...)`; the example used the
  R1-doc sketch (`freq_a, phi_a, freq_b, phi_b, mac_min=`, fields `i_a/i_b`).
- **`frf_synthesis.py`** — `as_damping` infers the model from the keys and rejects a
  `"model"` key (now `{"alpha": ..., "beta": ...}`). `direct_frf` takes matrices, not an
  `FEModel`: the example now assembles once (`assemble_km`), passes `asm.Kff/asm.Mff` with
  free-partition DOF indices to `direct_frf`, and full-space `dof_map.index(node, "uz")`
  indices to `modal_frf` (mode shapes live in the full DOF space). `(node, dof)` tuples
  are *not* accepted by `resolve_dofs`; index lookup added in the example, no src change.
- **`pretest_efi.py`** — `EFIResult` exposes `efi`/`selected`/`history`
  (not `ed_final`/`logdet_history`); `SensorSelection.max_off_diagonal`
  (not `max_offdiag`).
- **`update_youngs.py`** — `update_model(model, parameters, targets, method="wls", ...)`
  (not `measured=`/`method="analytic"`); the parameter is now an explicit
  `Parameter(name="E", kind="E", target=1, relative=True, lower=0.5, upper=2.0)`
  multiplier so `result.p[0] * E0` remains the recovered modulus; iteration count read
  from `result.n_iter`. Passed `n_modes=N_FREQS` to avoid solving unused modes.
