## API pins made beyond the frozen contract (implementers please match)

The contract froze imports and a few semantics; the specs pin the remaining details the
examples rely on:

- DOF addressing everywhere: `(node_id, dof_code 1..6)`; `dof_map: dict[(int,int), int]` on
  `AssemblyResult` **and** `ModalResult` (fea.md §1, §6).
- `add_property(type="beam", material_id, A, Iy, Iz, J)` field names (fea.md §2.2).
- Damping dict: `{"model": "modal"|"rayleigh"|"structural", ...}` (dynamics.md §1);
  `direct_frf` rejects `"modal"`.
- `FRFResult.H` shape `(n_out, n_in, n_freq)` with `kind="receptance"` default.
- `pair_modes(...) -> list[ModePair(i_a, i_b, mac, dfreq_rel)]` (correlation.md §5).
- `effective_independence(phi, n_sensors) -> EfiResult(selected, ed_final, logdet_history,
  condition)`; `eliminate_by_mac(phi, n_sensors, max_offdiag=None) -> MacElimResult(selected,
  removal_order, max_offdiag)` (pretest.md §2–3).
- `update_model(model, parameters=[{"type","id","name","lower","upper"}], measured=
  {"freq_hz": ...}, method="analytic") -> UpdateResult(model, p, covariance, history,
  converged)`; input model never mutated (updating.md §4).

If any owner needs to deviate, flag it in their report and I will realign docs/examples in the
next round; the frozen contract itself is untouched.
