## Design notes

- **FSL** (Femtools Scripting Language) is an original line-oriented design: statements split
  on newlines/`;`, `#` comments, case-insensitive keywords, `KEY=value` options, comma lists,
  double-quote quoting. Commands: `NEW PROJECT`, `ADD NODE/MAT/PROP/ELEM`, `SPC`,
  `SOLVE MODES`, `MAC`, `SAVE`, plus `PRINT` convenience. Named results
  (`SOLVE MODES NAME=a` / `MAC A=a B=b NAME=x`) are stored in `engine.results`.
  `run()` returns the engine (tests read `engine.model`). Dependency-injectable
  `model_factory=` for core-free testing.
- **Lazy sibling imports everywhere**: `femtools.core/io/fea/dynamics/correlation/pretest/updating`
  are imported inside command handlers. Missing modules produce a clear `ScriptError`
  (engine) or a red message + exit code 3 (CLI) — verified while core/io were absent.
- **CLI**: model loading by extension (`.ftproj`/`.unv`/`.bdf`); `frf` maps `NODE:DOF`
  (1-based) specs to global DOF indices via `ModalResult.dof_map.index(node, dof-1)`;
  `update` feeds a JSON config directly into `update_model(model, **config)`;
  `pretest` unpacks `EFIResult` duck-typed. Typer `Annotated` style (no B008 suppressions).
- **viz** is duck-typed against contract objects (works with any `nodes`/`elements` mapping,
  `ModalResult.modes/dof_map`, `FRFResult.H/freq_hz` or raw arrays). Edge tables for all
  Round-1 element types; 2D for planar models, 3D otherwise; `outfile=` saves, returns Figure.
- **GUI** is a local web app (runs fully headless): `GET /` HTML page,
  `GET /api/status|model|results`, `POST /api/script`, `GET /api/plot/{mesh,mode,mac}` (PNG).
  stdlib backend always available; FastAPI/uvicorn used when installed (`backend="auto"`).
  Note: FastAPI backend must not use `from __future__ import annotations` (function-local
  pydantic model would break annotation resolution — documented in `webapp.py`).
