## Frozen APIs delivered

```python
from femtools.io.inp import read_inp, write_inp, InpError   # write_inp = the optional extra
from femtools.io.kfile import read_k, KFileError
```

`InpError` and `KFileError` subclass `femtools.core.errors.FileFormatError`
(hence `ValueError`), matching `BdfError`/`CdbError`.  Unknown keywords are
skipped with **one aggregated `UserWarning` per keyword name** (`x<count>`),
exactly the BDF unsupported-card convention; degradations (midside drops,
wedge skips, non-uniform shell thickness, missing J) are aggregated notes,
never errors.

## Subset actually parsed — Abaqus .inp (`io/inp.py`)

* `*HEADING` (first data line -> model name).
* `*NODE` (`NSET=` collected), `id, x[, y[, z]]`, blanks = 0.
* `*ELEMENT, TYPE=` with `ELSET=` collected:
  C3D8/C3D8R/C3D8I -> HEX8, C3D4 -> TET4, S4/S4R -> QUAD4, S3/S3R -> TRIA3,
  B31 -> BEAM2, T3D2 -> BAR2.  Unsupported TYPEs skip the whole block with
  an aggregated warning.
* `*NSET`/`*ELSET` incl. `GENERATE` (first, last, inc) and set-name
  references in data lines; repeated blocks append; stored on
  `model.sets` as `NodeSet`/`ElementSet` (an elset colliding with an
  nset name is stored as `name:ELSET` with a note).
* `*MATERIAL, NAME=` + `*ELASTIC` (TYPE=ISOTROPIC only; `E, nu`; first
  row, temperature dependence warned) + `*DENSITY` (first row).  Unknown
  keywords do **not** close the material definition, so `*ELASTIC` /
  `*PLASTIC` / `*DENSITY` sequences keep their density (pinned by test).
* `*SOLID SECTION, ELSET=, MATERIAL=` — solids: material binding;
  on a T3D2 elset the data line is the truss area (default 1.0) ->
  femtools `bar` property.
* `*SHELL SECTION, ELSET=, MATERIAL=` — data line 1 thickness -> `t`.
* `*BEAM GENERAL SECTION` — data lines `A, I11, I12, I22, J` /
  `n1 direction` (blank -> default (0,0,-1)) / `E, G`; density from the
  `DENSITY=` parameter; an auto material per section
  (`nu = E/2G - 1`).  `I12` warned-ignored; missing `J -> I11 + I22`
  with a warning (the CDB BEAM3 practice).
* `*BEAM SECTION, SECTION=RECT|CIRC` — closed-form A/I11/I22/J
  (rectangle torsion via the Roark/Timoshenko formula), `MATERIAL=`
  honoured, direction line 2.
* `*BOUNDARY` — `node|nset, first[, last[, value]]` and the named types
  ENCASTRE/PINNED/{X,Y,Z}SYMM/{X,Y,Z}ASYMM; value -> enforced SPC.

Axis convention (documented in the module): the section 1-axis `n1` is
stored as the femtools beam `orientation` (local x-y plane == local y),
therefore **I11 -> Iy, I22 -> Iz** (bending about the 1-axis deflects in
the 2-direction).  Keyword/data continuation = trailing comma; a keyword
line after a trailing comma flushes instead of being swallowed (tested).
Elements without a section assignment, sections on undefined elsets,
double assignment, bad numbers, data before any keyword -> `InpError`.

`write_inp` (optional API) emits the same subset: `*HEADING`, `*NODE`,
`*ELEMENT` grouped per (property, type) under auto `ELSET=EL_P<pid>`,
`*MATERIAL/*ELASTIC/*DENSITY`, per-property `*SOLID/*SHELL SECTION` or
`*BEAM GENERAL SECTION` (beam-only materials are embedded there),
`*BOUNDARY` runs, `*NSET`/`*ELSET`.  MASS/SPRING/DAMPER and loads are
skipped with aggregated warnings (no subset mapping).

## Subset actually parsed — LS-DYNA .k (`io/kfile.py`)

Standard fixed-width cards (I8 node/element ids, E16 node coordinates,
10-char fields elsewhere) **and** comma free format, per line; `$`
comments; `_TITLE` variants of MAT/SECTION (and `*PART`, which always
carries its heading card); `*END` stops parsing.  Long/I10 format
markers (`*NODE +`/`%`) raise (refusing beats misparsing fixed columns).

* `*KEYWORD` (options ignored), `*TITLE` -> model name.
* `*NODE` `nid x y z tc rc`; constraint codes 1-7 -> SPCs (sid 0, like
  BDF GRID PS), tc translations / rc rotations.
* `*ELEMENT_SOLID` one-line `eid pid n1..n8` and the documented two-line
  form (`eid pid` / `n1..n10`).  Degeneracy collapse by unique corners:
  8 -> HEX8, 4 -> TET4 (n4 repeated); two-line 10-node = TET10 -> TET4
  with a midside-drop warning; wedges/pyramids skipped with a warning.
* `*ELEMENT_SHELL` `eid pid n1..n4[n5..n8]`; n4 duplicated/blank ->
  TRIA3; 8-node shells drop midsides with a warning.
* `*ELEMENT_BEAM` `eid pid n1 n2 n3`; n3 = orientation node ->
  `orientation = xyz(n3) - xyz(n1)`.
* `*MAT_ELASTIC` `mid ro e pr` -> isotropic material (extra cards
  warned).
* `*SECTION_SOLID` `secid`.
* `*SECTION_SHELL` card 2 `t1..t4`; thickness = T1, non-uniform warned.
* `*SECTION_BEAM` by ELFORM: 2 (resultant) `A, ISS, ITT, IRR, SA`
  (**ISS -> Iy, ITT -> Iz, IRR -> J**, missing J -> ISS+ITT warned,
  SA -> Asy/Asz attrs for the Timoshenko path); 1 (Hughes-Liu) CST=0
  rectangle / CST=1 tube from the TS/TT diameters via closed forms;
  3 (truss) `A` -> femtools `bar`, its `*ELEMENT_BEAM`s become BAR2.
* `*PART` title + `pid secid mid` (card pairs may repeat) -> one
  femtools Property per part (id = pid, name = title).
* `*BOUNDARY_SPC_NODE` `nid cid dofx..dofrz` (sid 1); CID != 0 warned
  and applied globally.

Malformed decks (duplicate ids, dangling part/section/material refs,
unsupported ELFORM/CST, bad numbers, missing cards, no keywords at all)
-> `KFileError`.  No `write_k` (not in the frozen API).
