**DOF convention (load-bearing for the other agents):** 6 DOF per node, local DOFs **0-based** (0..5 = UX,UY,UZ,RX,RY,RZ). Global numbering: nodes ascending by id, 6 consecutive DOFs per node; `FEModel.dof_map() -> dict[(node_id, dof), eq]`, `FEModel.dof_index()` gives the inverse row labels, `FEModel.active_dof_mask() -> (ndof,) bool` (True = free). Translators convert Nastran components `1..6` / UNV directions `±1..6` at the boundary.

## Known gaps / deviations (Round 1)

**UNV**
- Only the listed datasets; 55 supports analysis types 2 (normal) and 3 (complex) — other analysis types are skipped with a warning; assembled `ModalResult` requires consistent node sets (union with zero-fill + warning otherwise).
- Dataset 58: functions with mismatched frequency axes are kept in `UnvData.functions` but excluded from the assembled `FRFResult`; incomplete out×in grids are zero-filled with a warning. Binary 58b is not supported.
- Record-7 abscissa min/increment is spec-fixed at E13.5, so an even frequency axis roundtrips to ~1e-5 relative (ordinates are E20.12 → 1e-12).
- UNV carries no property/material cards in this subset: element `property_id` labels roundtrip, but `properties`/`materials` dicts stay empty on read (validation flags this as expected).
- 164 length/force factors rescale coordinates only; mode-shape/FRF ordinates are not rescaled (unit of the ordinate is not identifiable from the subset) — warned explicitly.

**BDF**
- CTETRA/CHEXA midside nodes are dropped (TET10→TET4, HEX20→HEX8) with a warning.
- PBEAM: end-A section only; tapered data ignored (warned). CONM2 offsets/inertia ignored (warned). PSHELL MID2/MID3 ignored (warned).
- CORD2* referencing a non-zero RID unsupported (assumed 0, warned). CORD1*/INCLUDE not supported (warned).
- `Node.cd` (displacement system) is stored as metadata; solvers in Round 1 work in global coordinates. GRID CP is resolved to global on read; written back as CP=0 with global coordinates (equivalent geometry).
- SPC writes one card per entry (no THRU compaction) — valid, just verbose.

**Extension note for other agents:** `FEModel.loads: list[Load]` exists beyond the contract field list (needed for FORCE/`solve_static`); `ModalResult` has optional `dof_index`/`damping` trailing fields. Both are backward compatible with the frozen signatures.
