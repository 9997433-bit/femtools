## Headline result — modal vs direct FRF on a 2-DOF system

Requested check: 2-DOF system, **all modes kept**, modal FRF vs direct FRF, relative L2 error.

System: `m1 = 2`, `m2 = 1`, `k1 = 1000` (to ground), `k2 = 800` (coupling).
Natural frequencies **2.673183 Hz** and **5.992962 Hz**. Full 2x2 FRF matrix, 1500 lines over
0.05–15 Hz. Error metric `||H_modal - H_direct||_F / ||H_direct||_F` over all lines and all
input/output pairs.

| Damping model | rel L2 | max pointwise rel |
|---|---|---|
| modal, `zeta = 0.02` | **4.37e-15** | 1.45e-14 |
| modal, per-mode `zeta = [0.01, 0.05]` | **7.81e-15** | 1.42e-14 |
| Rayleigh, `alpha = 0.5`, `beta = 1e-4` | **4.91e-15** | 2.07e-14 |
| structural, `eta = 0.03` | **3.57e-15** | 1.31e-14 |
| undamped | **8.82e-13** | 8.85e-13 |

All at machine precision, i.e. the two formulations are algebraically identical as
implemented. The undamped case is three orders looser purely because the FRF is real and
passes through zero at the antiresonance, so the normalisation is unforgiving near those
lines. The same errors hold for receptance, mobility and accelerance (4.37e-15, 4.16e-15,
3.60e-15) and reciprocity `H01 - H10` is exactly zero.

The reason the agreement is exact rather than merely close is that each damping model
exposes a modal *and* a physical view of the same physics, and the two are consistent by
construction (see "Damping" below). In particular `ModalDamping` builds the physical
matrix `C = M Phi diag(2 zeta_r omega_r) Phi^T M`, which reproduces the per-mode ratios
exactly when the basis is complete.

The check is available as library code, not just as a script:
`femtools.dynamics.verify_modal_vs_direct(K, M, modal, freq_hz, damping, band=...)` returns
`rel_l2`, `max_rel_pointwise` and both `FRFResult` objects.

### Contract acceptance case

`docs/CONTRACT_API.md` asks for modal vs direct within **5 %** on 0.2–0.8 fmax with 20 modes
and light damping. Measured: **1.26e-2 (1.3 %)** on a 40-DOF chain reduced to its lowest 20
modes, `zeta = 0.01`, drive at DOF 39, all 40 responses, band 1.382–5.526 Hz.

Note on how that case must be set up: `fmax` has to be the highest *retained* mode, not the
highest mode of the parent model. My first attempt kept 10 of 20 modes and took `fmax = f20`,
which puts the top of the 0.2–0.8 band at 8.03 Hz while the 10th retained mode sits at
6.70 Hz. The truncated model is then missing resonances that are physically inside the band
and the error is 78 % — correct behaviour for a badly-posed comparison, not a solver defect.
Flagging this because R1-G1 will write the acceptance test against this line of the contract.

## What is implemented

Twelve modules, 3031 lines. Public names are re-exported from `femtools.dynamics` and every
contract import path resolves.

| Contract import | Status |
|---|---|
| `femtools.dynamics.frf.modal_frf`, `direct_frf` | done |
| `femtools.dynamics.harmonic.harmonic_response` | done |
| `femtools.dynamics.mba.modal_based_assembly` | done |
| `femtools.dynamics.craig_bampton.craig_bampton` | done |
| `femtools.dynamics.time_domain.time_history` | done |
| `femtools.dynamics.residuals.residual_vectors` | done |

Beyond the contract: `fba.frf_based_assembly`, `mba.structural_dynamic_modification`,
`damping` (five models + `rayleigh_coefficients`), `modal.ModalModel`/`as_modal`, and
`synthetic` (the stand-in for the deferred `daq` package that `FILE_OWNERSHIP.md` asks for).

**FRF.** `FRFResult` holds `H` as `(n_out, n_in, n_freq)` `complex128` plus `freq_hz`, the
input/output DOF indices and the response type. Helpers: `magnitude`, `phase_deg`, `at(f)`,
`select`, and `as_response` to convert between receptance, mobility and accelerance.
`modal_frf` also accepts `lower_residual`/`upper_residual` truncation corrections.
`direct_frf` factorises the dynamic stiffness per line and works with dense or sparse K/M
(sparse vs dense agreement 9.9e-14), falling back to least squares on singular systems.

**Damping.** `ModalDamping` (scalar or per-mode zeta), `RayleighDamping` (alpha, beta),
`StructuralDamping` (loss factor eta), `ViscousDamping` (explicit C) and `CombinedDamping`
(superposition, also via `+`). Each provides `modal_terms -> (2 zeta_r omega_r, eta_r)` for
the modal denominator and `viscous_matrix`/`loss_factor` for the physical dynamic stiffness.
`as_damping` coerces scalars, arrays, `{"zeta": ...}`, `{"alpha": ..., "beta": ...}`,
`{"eta": ...}` and matrices. `rayleigh_coefficients(f1, f2, z1, z2)` inverts the Rayleigh
relation (round trip exact to 3e-18). `ViscousDamping.coupling_ratio` reports how
non-classical an explicit C is.

**Harmonic response / ODS.** `HarmonicResult.displacement` is the complex `(ndof, n_freq)`
operating deflection shape; `velocity`/`acceleration` derive from it. `ods(f, normalize=,
real=)` returns the shape at a line, phase-rotated so the dominant component is real.
`peak_frequencies()` finds the resonances from the response norm. Modal and direct methods
agree to 1.9e-12; for a unit load the ODS equals the corresponding FRF column to 9.2e-17; at
resonance the ODS matches the mode shape with `1 - MAC = 5.1e-4`.

**Residual vectors.** MacNeal residual flexibility: static response to the load directions,
stripped of the retained-mode content, mass-orthonormalised, then a small eigenproblem gives
K-orthogonal residual vectors with pseudo-frequencies. Free-free models are handled by
inertia relief (rigid-body content is removed from the load and the rigid subspace is pinned
with `M Phi_rb Phi_rb^T M`, which shifts the rigid eigenvalues without touching the elastic
subspace). On a 20-DOF chain keeping 6 modes, truncation error 3.71e-3 drops to **4.65e-5**
with residual vectors (80x) and to 2.47e-4 with the static residual term alone (15x).
`ResidualVectorResult.augment(modal)` returns the extended basis; `upper_residual(...)`
returns a block ready for `modal_frf`.

**Craig-Bampton.** Constraint modes `-K_ii^-1 K_ib` plus mass-normalised fixed-interface
modes; `n_modes=0` degenerates to Guyan. Returns the reduced K/M, the basis `T` in the
*original* DOF ordering, the fixed-interface frequencies, and `solve_modes()` to expand back
to full DOFs. On a 24-DOF chain with 3 boundary DOFs, the error on the first 4 frequencies
falls monotonically 3.6e-1 / 1.5e-1 / 2.0e-2 / 2.0e-3 / 6.5e-5 for 1/2/4/8/16 modes, and is
exact (1.2e-14) with the complete interior basis. Guyan is over-stiff as expected. Sparse and
dense paths agree to 3.6e-14.

**MBA / SDM.** `structural_dynamic_modification` solves
`(Lambda + Phi^T dK Phi) q = lambda (I + Phi^T dM Phi) q`, projecting discrete springs and
masses directly into modal space (no `ndof x ndof` matrix is formed; the sparse `dK`/`dM` are
returned for reference). With the complete basis it reproduces a re-solved modified
eigenproblem to 2.1e-15 and the modes come out mass-normalised w.r.t. `M + dM` to 8.3e-16.
`modal_based_assembly` stacks component modal models block-diagonally and ties them either
rigidly — exact elimination through the null space of the compatibility constraints — or
elastically. Rigid coupling of a chain split in two reproduces the monolithic frequencies to
6.9e-15 with interface compatibility satisfied to 2.2e-16; the penalty option converges to
the same answer. Results subclass `ModalModel`, so an assembled or modified model feeds
straight into `modal_frf`.

**FBA.** Lagrange-multiplier frequency based substructuring:
`Y_c = Y - Y B^T (B Y B^T)^-1 B Y`. Coupling a chain split into a 4-DOF and a 5-DOF component
reproduces the monolithic direct FRF to **1.65e-14** relative L2, with the duplicated
interface DOFs carrying identical responses (1.4e-16) and reciprocity to 8.4e-16.

**Time history.** Modal superposition with the Nigam-Jennings exact recurrence for
piecewise-linear loads (unconditionally stable, exact for such loads), plus a Newmark
variant. Coefficients are evaluated in complex arithmetic so over-damped modes work, and
zero-frequency rigid-body modes get their own exact recurrence with series expansions for
small `c*dt` to avoid cancellation. Free decay matches the analytical envelope to 1.0e-13;
seeded at steady state the response tracks the FRF prediction to 6.2e-7 (limited only by the
piecewise-linear sampling of the cosine); from rest the transient settles onto the same
steady state to 8.0e-6; rigid-body momentum balance on a free-free chain holds to 5.5e-14.
Structural damping is not causal in the time domain and is converted to `zeta = eta / 2`
with a `RuntimeWarning`.

**Synthetic data.** `synthetic_frf` (proportional complex noise), `synthetic_time_response`
(impulse / random / burst-random excitation with output noise), plus `band_limited_noise`,
`burst_random` and `impulse`. All seeded and reproducible; `SyntheticTest.truth` carries the
ground-truth modal data for MPE and updating work.

## Interfaces to other agents

**Modal input is duck-typed and I import nothing from other agents' packages.** `as_modal`
accepts `femtools.fea.eigen.ModalResult` (anything with `freq_hz` and `modes`, optionally
`eigenvalues`, `generalized_mass`, `dof_ids`), a `ModalModel`, a mapping, or a
`(freq_hz, modes)` tuple. Verified against a stand-in dataclass with R1-O1's field names.
Non-mass-normalised bases are renormalised internally via `generalized_mass`, so
`Phi.T M Phi = I` is convenient but not required. `femtools.dynamics` therefore imports
cleanly on its own today, before `femtools.fea` exists.

Everything is pure numpy/scipy on matrices and modal data, so nothing here blocks or is
blocked by R1-O1, O3 or O4.

### Notes for R1-G1 (tests)

- `direct_frf(K, M, inputs, outputs, freq_hz, damping)` mirrors the contract's `modal_frf`
  argument order. `inputs`/`outputs` accept an int, a sequence, a boolean mask or `None`
  (all DOFs).
- `direct_frf` with `ModalDamping` needs the basis to build the equivalent physical `C`:
  pass `modal=...`. It raises a clear `ValueError` otherwise. Rayleigh, structural and
  explicit-C damping need no modal input.
- Per-mode `eta` cannot be mapped to one physical loss factor; `direct_frf` rejects it. Use a
  scalar `eta` when comparing modal against direct.
- Hitting an undamped resonance exactly emits a `RuntimeWarning` and returns a very large
  value rather than `inf`/`nan`.
- See the `fmax` caveat above before writing the 5 % acceptance test.

## Verification

60 numerical checks across all eleven areas: modal-vs-direct equivalence (5 damping models,
3 response types), the contract truncation case, sparse/dense equivalence, harmonic response
and ODS, residual vectors including free-free inertia relief, Craig-Bampton convergence and
exactness, SDM against a re-solved eigenproblem, MBA rigid/penalty/elastic coupling and
residual-augmented truncation, FBA against a monolithic model, four time-integration checks,
and the damping and synthetic-data helpers. Plus interop checks (duck-typed `ModalResult`,
generalized-mass renormalisation, damping coercion) and 12 error paths.

Two of the four initial failures were bad test expectations (the `fmax` band described above,
and a Craig-Bampton tolerance tighter than the method's accuracy at that truncation). The
other two were real diagnostic work:

- The time-history steady-state check failed at 7.4e-2 because the transient had not decayed:
  `zeta = 0.03` on a 1.43 Hz first mode over 6 s leaves 32 % of the initial amplitude. Rather
  than just simulate longer, I seeded the integration at the exact analytical steady state,
  which turns the check into a sharp test of the recurrence at every sample instead of only
  in the tail, and separately verified that starting from rest converges to the same place.
- A dt-refinement check failed at 5.1e-11. The residual *grows* with refinement (6.9e-12,
  1.3e-11, 5.1e-11, 1.0e-10 for 2x/4x/8x/16x) while the absolute difference stays at
  1e-14 to 1e-13, which is round-off accumulating over more steps, not discretisation error.
  The recurrence is exact for piecewise-linear loads as intended; the tolerance was wrong.
